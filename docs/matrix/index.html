Runtime Complexity

Addition: O(n × m)

Multiplication: O(n × m × p)

Transpose: O(n × m)

Determinant: O(n!) in this recursive implementation

* Where n = rows, m = columns, p = shared dimension

What this module demonstrates

  • Element-wise matrix addition
  • Standard matrix multiplication
  • Matrix transpose
  • Determinant calculation

The visualization illustrates the operations; it does not benchmark or compare optimized multiplication strategies.

Complexity notes

Complexity depends on the operation and matrix dimensions. For square n × n matrices, standard multiplication takes O(n³); addition and transpose each touch O(n²) entries. This implementation computes determinants by recursive cofactor expansion, which has factorial worst-case time.

These are theoretical operation counts, not measured performance guarantees.
