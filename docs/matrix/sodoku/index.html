🎯 How Sudoku Solver Works

🔍 Non-MRV Strategy

Simple row-by-row, column-by-column scanning. Takes the first valid number and backtracks when stuck.

O(9^(n²)) worst case

⚡ MRV Strategy (Minimum Remaining Values)

Chooses the cell with the fewest valid candidates first. Dramatically reduces search space.

O(9^(n²)) but ~10-100x faster in practice

🧠 Why It's Challenging

Sudoku is NP-complete. The challenge is minimizing backtracking through smart heuristics like MRV.

"Evil" puzzles can take millions of iterations
