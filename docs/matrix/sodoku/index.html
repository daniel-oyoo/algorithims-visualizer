Introduction

A puzzle game on a matrix with these rules: Every row, column, and zone (a square matrix of size square root of the whole) should have a single unique number from 1 to the size of the matrix.

Sudoku is NP-complete. The challenge is minimizing backtracking through smart heuristics like Minimum Remaining Values (MRV).

Why It's Challenging

  • NP-Complete Problem - No polynomial-time solution exists
  • Backtracking Explosion - "Evil" puzzles can take millions of iterations
  • Heuristic Selection - Choosing the right strategy makes all the difference

How It Works

Understanding the two solving strategies

Non-MRV Strategy

Simple row-by-row, column-by-column scanning. Takes the first valid number and backtracks when stuck.

O(9^(n²)) worst case

MRV Strategy (Minimum Remaining Values)

Chooses the cell with the fewest valid candidates first. Dramatically reduces search space.

O(9^(n²)) but ~10-100x faster

Backtracking

Systematically tries numbers and undoes choices when stuck. Works for any size Sudoku grid.

Non-MRV - Simple Row-by-Row

Sudoku is filled row by row, backtracking when stuck. Done through iteration or recursion.

Best: O(n) Average: O(n²) Worst: O(9^(n²)) 
function solve(row, col):
    if row == n:
        return true
    if col == n:
        return solve(row + 1, 0)
    if grid[row][col] != 0:
        return solve(row, col + 1)
    for num in 1..n:
        if valid(row, col, num):
            grid[row][col] = num
            if solve(row, col + 1):
                return true
            grid[row][col] = 0
    return false

MRV - Smart Cell Selection

Sudoku is filled cell by cell starting with the cell with fewest remaining values or options.

Best: O(n) Average: O(n log n) Worst: O(9^(n²)) 
function solveMRV():
    cell = findCellWithMRV()
    if cell == null:
        return true
    for num in candidates:
        if valid(cell, num):
            place(cell, num)
            if solveMRV():
                return true
            remove(cell, num)
    return false

function findCellWithMRV():
    minCandidates = INF
    for each empty cell:
        candidates = getValidNumbers(cell)
        if candidates.size < minCandidates:
            minCandidates = candidates.size
            selected = cell
    return selected

My Non-MRV - Iterative with Stack

Sudoku is filled row by row, backtracking when stuck. Done through iteration using manual stack and flags.

Best: O(n) Average: O(n²) Worst: O(9^(n²)) 
function solveIterative():
    stack = []
    row = 0, col = 0
    while row < n:
        if col == n:
            row++
            col = 0
            continue
        if grid[row][col] != 0:
            col++
            continue
        num = getNextNumber(row, col)
        if num == 0:
            // Backtrack
            if stack.empty():
                return false
            row, col = stack.pop()
            grid[row][col] = 0
            col++
        else:
            grid[row][col] = num
            stack.push([row, col])
            col++
    return true
