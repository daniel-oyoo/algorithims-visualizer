Definition

A puzzle game on a matrix with these rules

Every row ,column and zone(depends on size but its a square matrix of size square root of the whole),
should have a single unique number form 1 to size of matrix

Approaches

Non-MRV

Sodoku is filled row by row and backtracking on getting stuck-either done through iteartion or recursion

MRV

Sodoku is filled cell by cell startig with cell with fewest remaining values or options and backtracking on getting stuck-either done through iteartion or recursion

My Non-MRV

Sodoku is filled row by row and backtracking on getting stuck- done through iteartion using manual stack and flags
