Hybrid -fast and accurate

Well with the above options i asked myself quadratic time set up is a pain and inaccuracy on sparse graphs is unacceptable,
why not combine all the above methods into one - and thats what i did.
This hybrid versions main strategy is where we mainly scan down the main diagonal as log as we find a start cell of any zone.
(This handles dense graphs with elagant time) But things dont alwyas go this well so if we dont find a start cell of sany zone in our diagonal path, we fall back to left and right scan withn the row and proces the first cell of any zone within the row
Then proceed with our diaagonal path. Note : without breaks in the left right row search (its will behave like basic ) and degrade to quadratic time
This has the most iterstig patten and actually try it out comment or disbale the rule for eft right search and compare your results.

  • Best case : linear plus work done-foound max start cell in the main diagonal .
  • Avarage case : linear plus work done-We mostly scan two to 3 cells in every row .
  • Wost case : quardratic plus work done zones near edges so we scan almost everything .
