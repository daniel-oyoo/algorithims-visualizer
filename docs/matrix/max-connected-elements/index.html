Introduction

After struggling for weeks to find the largest basin (impossible since no two basins can be adjacent), I stumbled across flood fill. But it was no easy ride to get the right mental model.

Major Culprits

  • Cycles due to repetitions - mark visited to solve it
  • Bounds and index errors - enforce tight bounds check

The major question that kept haunting me: "Is quadratic time setup the least effort to do this work?" Turns out not always. Here I show you approaches from direct/basic to Las Vegas/Monte Carlo style approximations that are up to 10x faster than direct and still somehow accurate.

How It Works

Understanding the dual-wave search process

Search Wave

Scans the grid row by row looking for unvisited positive cells. When found, it triggers the infection wave.

O(n × m) Scan

Infection Wave (Flood Fill)

Recursively spreads to all connected neighbors (4-way or 8-way), marking and counting the entire component.

O(n × m) Flood Fill

Component Analysis

Each component is assigned a unique color and tracked with its starting cell and total cell count.

Algorithm Approaches

Click on any approach to expand and view details

Basic/Direct - Absolute Accuracy

Scan every cell, and if it's a member of any zone, initiate flood fill.

Best: O(n²) Average: O(n²) Worst: O(n²) 
Loop : i = 0 to n-1 
    Loop : j = 0 to n-1
        if cell(i,j) valid
            process
        end if
    end Loop
end Loop

Improved Basic - Mostly Accurate

For every row only look for the first occurrence of a start of zone cell.

Best: O(n) Average: O(n²) Worst: O(n²) 
Loop : i = 0 to n-1 
    Loop : j = 0 to n-1
        if cell(i,j) valid
            process
            i++
        else
            j++
        end if
    end Loop
end Loop

Accuracy - What's That?

This works by scanning a single linear path, mostly the main diagonal.

Best: O(n) Average: O(n) Worst: O(n) 
Loop : i = 0, j = 0 to n-1
    if cell(i,j) valid
        process
    end if
end Loop

Hybrid - Fast and Accurate

Combines all methods: scan main diagonal, fall back to left-right scan within row.

Best: O(n) Average: O(n) Worst: O(n²) 
Loop : i = 0 to n-1 
    Loop : j = 0 to n-1
        if cell(i,j) valid
            process
            i++, j++
        else if cell(i,j) is Visited
            i++, j++
        else
            Loop : left = i - 1 to 0
                if cell(i,j) valid
                    process
                    exit
                end if
            end Loop
            Loop : right = i + 1 to n - 1 
                if cell(i,j) valid
                    process
                    exit
                end if
            end Loop
        end if
    end Loop
end Loop
