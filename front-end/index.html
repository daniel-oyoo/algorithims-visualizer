📖 Algorithm Documentation & Implementation Details

🔍 Connected Components (Flood Fill)

Implementation: Recursive DFS with 8-direction connectivity (including diagonals).

Algorithm: Scanning wave finds unvisited cells, then infection wave performs flood fill using findMaxConnnected().

Time Complexity: O(rows × cols) | Space: O(rows × cols)

🍊 Rotten Oranges

Implementation: BFS from all rotten oranges simultaneously.

Algorithm: Queue-based level-order traversal. Each level represents 1 minute of infection spread.

Time Complexity: O(rows × cols) | Space: O(rows × cols)

🌀 Spiral Matrix

Implementation: Four boundary pointers (top, bottom, left, right).

Algorithm: Traverse right → down → left → up, shrinking boundaries after each pass.

Time Complexity: O(n²) | Space: O(1)

🎯 Move Token

Implementation: DFS with cycle detection and custom movement rules.

Algorithm: Token moves by value of current cell (up/down/left/right). Marks visited cells to avoid cycles.

Time Complexity: O(rows × cols) | Space: O(rows × cols)

📏 Nearest Distance to Zero

Implementation: BFS from all zero cells (multi-source BFS).

Algorithm: Queue all zero positions, then expand outward layer by layer.

Time Complexity: O(rows × cols) | Space: O(rows × cols)

🧩 Sudoku Solver

Implementation: Backtracking with row/column/box validation.

Algorithm: Find empty cell, try numbers 1-9, validate, recurse, backtrack if invalid.

Time Complexity: O(9^(n²)) worst-case | Space: O(n²)
